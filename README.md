# AOI UI Prototype
**Academic Operations Intelligence (AOI)** for Mindanao State University - Zamboanga Sibugay.

This repository contains the frontend UI prototype built with React, Vite, and Tailwind CSS. It demonstrates the complete user flow, including institutional login, the student portal, AI chat routing (with PII consent gateways), and the admin audit log.

### ⚠️ Note
This is a UI prototype. All AI responses and audit logs are currently mocked. The actual backend (Python Intent Router, Ollama models, and ChromaDB RAG pipeline) is built separately in Track B.

### How to Run
`npm install`
`npm run dev`
